# Демо-интерфейс

Это маленький веб-интерфейс на вашем компьютере. Он принимает объявление о ремонте (файлом CSV или одним текстом), находит услуги категорий 102–106 и показывает черновик объявления для каждой найденной услуги. Дополнительные пакеты ставить не нужно: сервер написан на стандартной библиотеке Python, страница — один файл `index.html` без внешних ресурсов.

Категории: 102 — штукатурные работы, 103 — плитка, 104 — сантехника, 105 — электрика, 106 — малярные работы и обои. Категория 101 — это исходная категория объявления.

## Подготовка перед демо

### 1. Установите и запустите Ollama

Скачайте Ollama с официального сайта и установите её. После установки она обычно запускается сама и работает в системном трее. Если нет, запустите сервер вручную:

```powershell
ollama serve
```

### 2. Проверьте, что модель на месте

```powershell
ollama list
```

В списке должна быть строка `hf.co/t-tech/T-lite-it-2.1-GGUF:Q4_K_M`. Если её нет, загрузите модель:

```powershell
ollama pull hf.co/t-tech/T-lite-it-2.1-GGUF:Q4_K_M
```

### 3. Прогрейте модель пробным запросом

Первый вызов модели после запуска может быть очень долгим: однажды он завис на 14 минут. Поэтому за несколько минут до демо отправьте пробный запрос и дождитесь ответа.

```powershell
ollama run hf.co/t-tech/T-lite-it-2.1-GGUF:Q4_K_M "Скажи одно слово: готово"
```

Когда модель ответила, выйдите из диалога командой `/bye`. Модель остаётся в памяти ещё 30 минут (параметр `keep_alive` в конфигурации), поэтому прогревайте её незадолго до показа.

### 4. Задайте переменные окружения PowerShell

Эти переменные нужны только для текущего окна PowerShell. Они делают вывод в кодировке UTF-8 и подключают исходный код проекта.

```powershell
$env:PYTHONUTF8 = "1"
```

```powershell
$env:PYTHONPATH = "src"
```

Если хотите, чтобы Ollama обрабатывала несколько запросов одновременно, задайте это до запуска `ollama serve`. Для демо это не обязательно.

```powershell
$env:OLLAMA_NUM_PARALLEL = "1"
```

## Запуск

Откройте PowerShell в корне репозитория (там, где лежат папки `app`, `src`, `configs`) и выполните команду:

```powershell
.venv\Scripts\python app\server.py
```

В консоли появится строка с адресом. Откройте его в браузере:

```
http://127.0.0.1:7860
```

Адрес и порт берутся из `configs/default.yaml`, раздел `demo`. Остановить сервер можно сочетанием Ctrl+C в том же окне.

## Как пользоваться

В шапке страницы есть индикатор состояния. Зелёная точка означает, что Ollama работает и модель на месте. Жёлтая или красная точка означает проблему, а подсказка по наведению мыши объясняет, какую именно. Нажмите на индикатор, чтобы проверить состояние заново.

Над вкладками обработки находятся общие настройки:

- **Режим судьи.** `panel` — три эксперта, точнее, но медленнее (значение по умолчанию). `single` — один судья, быстрее.
- **Черновики.** `template` — быстрый шаблон из фраз исходного объявления (по умолчанию). `llm` — черновики пишет модель, это заметно медленнее.
- **Добавлять 101.** Если галочка стоит, категория 101 добавляется в список категорий каждой строки результата. По умолчанию она включена.

### Вкладка «Файл»

1. Перетащите CSV-файл в рамку или нажмите на рамку и выберите файл. В файле должны быть столбцы `testcase` и `description`.
2. Нажмите «Запустить». Появится полоса прогресса с числом обработанных строк и прошедшим временем.
3. Одновременно выполняется только одна обработка. Если запустить вторую, интерфейс покажет сообщение и не примет её.
4. После окончания появится таблица. Нажмите на строку, чтобы раскрыть черновики (заголовок и текст каждого) и блок «Исходное описание». Кнопки «Раскрыть все» и «Свернуть все» работают сразу для всей таблицы.
5. Кнопка «Скачать CSV» отдаёт файл в том же формате, что и `scripts\make_submission.py`: столбцы `testcase`, `microcats`, `descriptions`, причём два последних — списки в формате JSON.

В столбце «Источник» видно, как найдены категории. Значение `keywords_fallback` значит, что языковая модель была недоступна и категории найдены по ключевым корням. Значение `error` значит, что строка обработалась с ошибкой; остальные строки файла при этом обрабатываются как обычно.

### Вкладка «Один текст»

Вставьте текст объявления, нажмите «Обработать» и дождитесь результата. Пока идёт обработка, показывается индикатор. Результат выводится в два столбца: слева исходный текст, справа найденные категории и черновики.

### Предыдущие отправки

Каждая завершённая обработка (файл или одиночный текст) автоматически сохраняется. На вкладке «Предыдущие отправки» виден список. Нажмите на любую строку списка, чтобы открыть ту же таблицу результата и скачать для неё CSV.

Файлы лежат в папке `app\submissions\<дата-время>\`:

- `meta.json` — имя файла, время, параметры, число строк, длительность;
- `results.jsonl` — подробный результат по каждой строке;
- `out.csv` — готовый CSV для бота.

Эта папка добавлена в `.gitignore` и в репозиторий не попадает. Чтобы удалить прошлые отправки, удалите папку `app\submissions`.

## Если что-то пошло не так

### Порт 7860 занят

Сервер напишет, что не смог занять порт. Скорее всего, прежний запуск ещё работает. Найдите процесс, который слушает порт:

```powershell
Get-NetTCPConnection -LocalPort 7860 -State Listen
```

Остановите его по номеру из столбца `OwningProcess` (подставьте свой номер вместо `12345`):

```powershell
Stop-Process -Id 12345
```

Либо измените `demo.port` в `configs/default.yaml` и откройте новый адрес.

### Ollama не отвечает

Индикатор в шапке будет красным, а в результатах появится предупреждение. Интерфейс продолжит работать: категории найдутся по ключевым корням (источник `keywords_fallback`), но без участия модели. Для режима черновиков `llm` текстов от модели в этом случае не будет. Проверьте, что Ollama запущена:

```powershell
Invoke-RestMethod http://localhost:11434/api/tags
```

Если команда выдаёт ошибку, запустите `ollama serve` и нажмите на индикатор в шапке.

### Нужной модели нет

Индикатор жёлтый, подсказка говорит, что модели нет в списке. Загрузите её командой из пункта 2 раздела «Подготовка перед демо» и снова проверьте `ollama list`.

### Нет файла artifacts\tfidf\model.joblib

Без этого файла не работает быстрый классификатор слоя 1. Обучите его двумя командами, по очереди:

```powershell
.venv\Scripts\python scripts\prepare_data.py
```

```powershell
.venv\Scripts\python scripts\train.py
```

После обучения перезапустите сервер.

### Обработка идёт очень долго или зависла

Первый вызов модели бывает долгим. Если полоса прогресса не двигается больше нескольких минут, остановите сервер (Ctrl+C), убедитесь, что модель отвечает на пробный запрос (пункт 3 подготовки), и запустите заново. Для быстрого показа выберите режим судьи `single` и черновики `template`.
